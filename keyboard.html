About this prototype

Working

  • ✓Every word in the passage is explained by the same engine that places the marks. Nothing is hand-written per word.
  • ✓LO tone placement (§IX): multiple vowels, syllabic nasals, y, initialisms
  • ✓Nasalization ⁿ, open o', neutral tone, formal to convenience spellings
  • ✓119 tests against the manual's worked examples, including this passage in both spelling styles

Not built

  • ·Text-to-speech. Needs recorded Lánnang-uè audio; none is bundled here.
  • ·Speech-to-text. Needs an evaluated model. LanCorp is CC BY-NC, consent scoped to academic use.
  • ·Chinese-character candidates. The suggestion strip already proves the interaction; what is missing is a reviewed LO to Hanzi dataset, not the interface. LO token → reviewed source → ranked candidates → selection
  • ·Marvin's Dictionary / HokkienHub. Needs a documented API and permission.
  • ·Native iOS and Android keyboard. The engine is a pure string transducer, so it ports without rewriting the rules.
